Privacy policy

Purpose and data use

This personal utility uses Google Drive access to upload, list, read, verify, move and delete the backup files selected by the account owner. Its archive contents follow an explicit list of approved source files, instructions and sanitized operating records. Google account and file metadata support authorization, destination checks, integrity checks and recovery.

Permissions and storage

The authorized Drive permission covers the owner’s Google Drive files. The scheduled task uses the designated backup folder. Backup content is transferred to the Google Drive accounts selected by the owner. OAuth credentials are stored in restricted configuration storage on the owner’s computers. Local operational receipts record backup names, checksums and success or failure status.

Retention and control

The configured policy retains the latest two verified archives in each backup folder. The task moves older matching archives to Google Drive Trash after every configured destination passes verification. Google manages trash retention. The owner can manage stored files in Drive and revoke application access through Google Account connections.

Google API information

Information received from Google APIs serves the owner’s requested backup and file-management features. Its use follows the Google API Services User Data Policy, including the Limited Use requirements.

This information site

This site serves static application documentation through GitHub Pages. Hosting requests are handled under GitHub’s privacy statement. Application authorization is performed by Google and the local backup utility.

Contact

The operator is the owner of the classheavy6750 GitHub profile. The application is operated for that account owner’s personal backup workflow.
